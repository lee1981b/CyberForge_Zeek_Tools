# Branding assets

The repository homepage uses the account's existing public GitHub avatar by
URL, alongside blue project badges. The runtime tools do not contact those
image hosts; those images are only part of the rendered README.

Store any future original CyberForge banner or logo in this directory and
reference it with a relative path from the README. Keep artwork provenance
and permitted use documented. Do not copy the Zeek Project's branding in a way
that implies official endorsement.

The externally referenced account avatar and third-party marks are not covered
by this repository's software licence.
