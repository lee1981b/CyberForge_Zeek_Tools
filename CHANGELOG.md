# Changelog

## epochutc 1.0.0 - initial package

- Packaged the original CyberForge epoch-to-UTC Bash helper as a standalone tool.
- Retained six-digit fractional UTC output by default.
- Added optional nanosecond display, multiple-value processing, and explicit stdin mode.
- Added input validation, help/version output, dependency checks, and meaningful exit codes.
- Added per-user, system-wide, and custom-prefix Linux installation.
- Added overwrite protection, backup-on-explicit-replacement, and symlink refusal.
- Added manual installation, usage, container, contribution, and maintainer guides.
- Added a temporary-directory regression suite and a GitHub Actions workflow.
- Established a per-tool repository layout for future CyberForge Zeek utilities.

A local package version is not itself a GitHub release; tags and release dates
are recorded when the maintainer actually publishes them.
